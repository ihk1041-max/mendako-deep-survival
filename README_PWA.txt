メンダコ・ディープサバイバル v21 PWA
========================================

このフォルダ一式をHTTPSで公開すると、スマホのホーム画面へ
「アプリ」のように追加して起動できます。

■ v21 追加機能

・従来のサバイバルモードを維持
・敵やボスを攻撃して倒す「バトル」モードを追加
・バトルは自動照準／自動発射。スマホは移動とダブルタップダッシュに集中
・攻撃タイプ：あわショット、スターショット、すみボム、うずしお
・バトル専用の攻撃進化、敵HP、ボスHP、撃破数を追加
・ランキングは全モード／サバイバル／バトルで絞り込み可能
・既存のプロフィール、しんじゅ、途中保存との互換性を維持

■ 最も簡単な公開方法：GitHub Pages

1. GitHubで新しいRepositoryを作成します。
   例: mendako-game

2. このフォルダ内のファイルをすべてRepositoryのルートへアップロードします。
   index.html
   manifest.webmanifest
   service-worker.js
   icon-192.png
   icon-512.png
   icon-maskable-512.png
   apple-touch-icon.png
   favicon-64.png
   mendako.png

3. GitHubの Repository > Settings > Pages を開きます。

4. Build and deployment で次を指定します。
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   → Save

5. 数分待つとURLが表示されます。
   例: https://ユーザー名.github.io/mendako-game/

■ iPhone / iPad

1. 上記URLをSafariで開きます。
2. 共有ボタン（四角＋上矢印）をタップします。
3. 「ホーム画面に追加」を選択します。
4. ホーム画面の「メンダコ」アイコンから起動します。

※ iPhoneではChromeではなくSafariから追加するのが確実です。

■ Android

1. 上記URLをChromeで開きます。
2. ゲーム内の「ホームに追加」、またはChromeメニューを開きます。
3. 「アプリをインストール」または「ホーム画面に追加」を選択します。

■ PWA版の特徴

・ブラウザのアドレスバーがない、アプリ風の独立画面で起動
・一度読み込めばオフラインでも起動可能
・途中保存／「続きから」機能を維持
・ゲーム開始前に「やさしい／ふつう」を選択可能
・やさしい：ライフ5、ダイオウイカの攻撃予告を長く、危険な敵の挟み撃ちを防止
・縦画面／横画面の両方に対応（ゲーム中は横画面推奨）
・BGM、図鑑、実績、永続データを維持
・しんじゅショップは購入／購入済み／装備中を明示
・ゲーム中のMENUから途中保存してタイトルへ戻れます
・クリア／ゲームオーバー後もタイトルへ戻れます
・ホーム画面用の専用メンダコアイコン付き

■ 注意

・index.htmlをfile://で直接開いただけではPWAインストールできません。
  GitHub PagesなどのHTTPS公開が必要です。
・Service Workerの更新は自動で行われますが、更新直後に古い表示が残る場合は
  アプリを一度完全に閉じてから再起動してください。
・iOS/AndroidのOSジェスチャーをWebアプリから完全に禁止することはできません。
  そのため途中状態の自動保存機能は残しています。

■ PCでの簡易確認

このフォルダで以下を実行してください。

  python -m http.server 8000

その後、PCブラウザで http://localhost:8000/ を開きます。
localhostではService Workerをテストできます。


■ v16の主な改善

・スマホのダッシュボタンを右下から右中央寄りへ移動し、タップ領域も拡大
・スマホでは画面を素早く2回タップしてもダッシュ可能
・途中の手動ルート分岐を廃止。浅い海→薄明の海→深海は自動進行
・同じランダムイベントが連続しにくいよう調整
・「おさかなの群れ」「ラッキー生物を追え！」イベントを追加
・ラッキー生物は捕食すると追加スコア＋ダッシュ回復
・ミッションに「ダッシュ3回」「ニアミス2回」を追加
・ミッション連続達成で報酬が少しずつ増えるよう調整
・v15のスマホ成長サイズ補正、やさしい/ふつう、進化、図鑑、実績、しんじゅ、お守り、PWA、途中保存は維持
・既存の途中保存キー/スキーマは維持。v15でルート選択待ちだった保存も選択画面なしで復帰

■ v17の主な改善

・しんじゅ交換所のお守りを3種類から7種類へ拡張
・新お守り：リズム貝、宝さがし貝、ぱくぱく貝、サンゴのお守り
・購入済みのお守りは交換所からタップして装備変更可能
・しんじゅの長期的な使い道として「海の研究」を追加
・海の研究はヒレ／ダッシュ／コンボ／発見の4系統、各Lv.20まで強化可能
・研究費用はLvに応じて上昇し、4系統を全て最大にするには合計2,920個のしんじゅを使用
・研究効果は1Lvごとに小さくし、最大強化でもゲームバランスを壊しにくい設計
・ホタルイカ、オウムガイを図鑑と通常出現へ追加
・食べられる生き物に、ゆらゆら／くねくね／時々加速の泳ぎ方バリエーションを追加
・新ランダムイベント「きらきら回遊」を追加
・サメ／ダイオウイカ／シャチに複数の行動テンポを追加し、毎回まったく同じボス戦になりにくく調整
・やさしいモードでは急な連続型を避け、予告の分かりやすさを維持
・コンボが伸びるほど捕食効果音が少し高くなり、連続捕食の気持ちよさを強化
・v16のスマホダッシュ位置、2回タップダッシュ、分岐廃止、PWA、途中保存互換は維持



■ v19の主な改善

・しんじゅショップの所持数表示を追従固定し、下までスクロールしても残り個数を確認可能
・購入／研究後に所持しんじゅ表示が反応し、残額変化を分かりやすく改善
・スマホ画面上のダッシュボタンを完全撤去
・スマホのダッシュ操作は素早い2回タップに統一（PCはShift/Dを維持）
・ダッシュの残りクールタイムは小さなHUD表示のみとし、操作領域を邪魔しないよう変更
・毎ラン自動で1つ決まる「今回の潮」を追加（にぎやか潮／星くず潮／お宝潮／はやて潮）
・潮によって魚群、レア率、アイテム率、速度と得点などが少し変化し、同じ3分でも展開を変化
・ボスを一度も被弾せず突破すると「無傷ボス」ボーナスを獲得
・無傷ボスは追加スコアとしんじゅ報酬に反映
・成長時に小さなお祝い魚群が出現し、成長直後のテンポを改善
・v18までの図鑑、実績、しんじゅ、研究、お守り、PWA、途中保存キー／スキーマは維持


■ v20の主な改善
・家族用のローカルプロフィールを追加（最大8人）
・しんじゅ、研究、お守り、図鑑、実績、ベスト、途中保存をプロフィールごとに分離
・v19以前の既存データは最初のプロフィールへ自動移行
・今日 / 過去7日 / 総合の家族ランキングを追加
・ランキングは各プロフィールの期間内ベストスコアで比較
・結果画面に今日 / 1週間 / 総合順位を表示
・プロフィールの追加、切替、名前変更、削除に対応

※プロフィールとランキングは、このGitHub Pagesを開いている同一ブラウザのlocalStorage内に保存されます。
  別端末間で同期するオンラインアカウントではありません。別端末共通ランキングにはバックエンドが必要です。
